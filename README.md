# Puffinus-Spatial-Ecology

## Overview

This repository contains a comprehensive spatial ecology analysis of Mediterranean shearwaters (*Puffinus* species: Balearic *P. mauretanicus* and Yelkouan *P. yelkouan*). The project integrates GPS tracking data, environmental niche modeling, and connectivity analyses to understand migratory patterns, habitat use, and biogeographic population structure across the Mediterranean Sea.

### Key Questions Addressed

1. **Phenology**: How does breeding and non-breeding timing vary across populations?
2. **Spatial Distribution**: Where do populations occur year-round, and how do distributions differ seasonally?
3. **Migratory Connectivity**: Which breeding populations winter in which areas?
4. **Habitat Suitability**: What environmental factors drive habitat selection across seasons?
5. **Geographic Divergence**: How do habitat preferences diverge across biogeographic units?

## Known Issues & Troubleshooting

### **Issue 1: "File not found" errors**

**Symptoms**: Errors like `cannot open file 'data/colonies_coords.csv'`

**Solutions**:
- ✓ Check that `data/` subdirectory exists
- ✓ Place input files in correct subdirectory
- ✓ Verify file names match exactly (case-sensitive on Linux/Mac)
- ✓ Use `list.files("data/")` in R to verify contents

### **Issue 2: Package installation fails**

**Symptoms**: `Error: package 'xyz' could not be installed`

**Solutions for problematic packages**:

```r
# For embarcadero (spatial BART):
install.packages("embarcadero", dependencies = TRUE)

# For grec (gradient calculations):
install.packages("grec")

# For MigConnectivity (requires specific versions):
install.packages("MigConnectivity", dependencies = TRUE)

# If CRAN installation fails, try from GitHub:
remotes::install_github("cran/grec")
```

### **Issue 3: NetCDF files not found (Script 6)**

**Symptoms**: `Found 0 NetCDF files` in Script 6

**Solutions**:
- ✓ Download `.nc` files from Copernicus Marine Data Store
- ✓ Place them in repo root or modify path in Script 6 line 71:
  ```r
  wd <- "path/to/nc/files"  # Change this
  setwd(wd)
  ```
- ✓ Verify files match pattern `"*.nc"` with:
  ```r
  list.files(pattern = ".nc")
  ```

### **Issue 4: BART model training runs out of memory (Script 7)**

**Symptoms**: R crashes or extremely slow during `bart.step()`

**Solutions**:
- ✓ Reduce prediction grid resolution (change `splitby = 20` to `splitby = 50`)
- ✓ Decrease sample size in presence/absence data preparation
- ✓ Run on machine with ≥16GB RAM (32GB recommended)
- ✓ Close other applications to free memory

### **Issue 5: Undefined variable errors**

**Symptoms**: `Error: object 'group_membership' not found` or `CRS_GEO` undefined

**Status**: Known issues in scripts 4 and 9

**Fix**: Define missing variables at start of affected scripts:
```r
# Script 4 (add after line 63):
group_membership <- list(
  WesternMost = c("IBIZA", "MALLORCA"),
  CentralWest = c("MINORCA", "FRANCE", "SARDINIA"),
  CentralEast = c("MALTA", "CROATIA"),
  EasternMost = c("GREECE")
)
pop_order <- unlist(group_membership)

# Script 9 (add after line 40):
CRS_GEO <- "EPSG:4326"
```

### **Issue 6: Script 7 path bugs**

**Status**: Known bug at line 650

**Symptoms**: Output files not created, error about wrong path

**Fix**: Add missing `/` in Script 7:
```r
# Line 650 - change from:
filename = paste0(path.out.tx, "Taxa_pred_", p, ".tif")

# To:
filename = paste0(path.out.tx, "/Taxa_pred_", p, ".tif")
```

## Analysis Overview

### **1. Phenological Analyses** (`1_Phenolgy_analyses.Rmd`)
- **Method**: Linear mixed-effects models (LMM) with lunar phase predictors
- **Response**: Julian dates (lunar-referenced) of breeding arrival/departure
- **Predictors**: Colony, lunar illumination, year
- **Output**: Phenological estimates with 95% CI, timeline visualization

### **2. Non-Breeding Distributions** (`2_Non-breeding_distributions.Rmd`)
- **Method**: Kernel Density Estimation (KDE, bandwidth = 1.86°)
- **Data**: Core non-breeding months (Aug-Sep), standardized by individual & population
- **Output**: 50% and 90% utilization distributions (UD), group-level maps

### **3. Year-Round Distributions** (`3_Year-round_distributions.Rmd`)
- **Method**: Population-weighted density grids at 0.5° resolution
- **Data**: All trip data, 4 seasonal periods
- **Weighting**: Accounts for unequal tracking effort and population sizes
- **Output**: Seasonal density maps with marginal distributions

### **4. Migratory Connectivity** (`4_Migratory_Connectivity.Rmd`)
- **Method**: `estMC()` function from MigConnectivity package
- **Levels**: Taxon, biogeographic group, population, sub-population
- **Distance**: Marine cost-distance (ocean = 1, land = 0)
- **Output**: MC indices, psi matrices, chord diagrams

### **5. Presence Data Preparation** (`5_Prescence_data_preparation.Rmd`)
- **Method**: Spatial thinning by season, hierarchical weighting
- **Levels**: Population, unit (biogeographic), species, supra-taxa
- **Output**: `.RDS` files with presence locations for ENM training

### **6. Environmental Climatologies** (`6_Climatologies_preparation.Rmd`)
- **Method**: Daily-to-monthly aggregation, temporal standardization
- **Variables**: 12 oceanographic/meteorological layers
- **Output**: Mean & SD rasters per season at 0.25° resolution

### **7. ENM Runs** (`7_ENMs_run.Rmd`)
- **Method**: BART (Bayesian Additive Regression Trees) with `embarcadero`
- **Absence Data**: Random sampling equal to presence sample size
- **Validation**: AUC calculated on training data
- **Levels**: Population, biogeographic unit, species, supra-taxa
- **Output**: Probability of suitability maps (0-1 scale)

### **8. ENM Results** (`8_ENMs_results_extraction.Rmd`)
- **Method**: Partial dependence plots from fitted BART models
- **Variables**: 5-7 per season (selected by model)
- **Output**: Partial response curves with 95% CI bands

### **9. Projections & EMD** (`9_Projections_EMDs.Rmd`)
- **Method**: Earth Mover's Distance (EMD) between suitability distributions
- **Distance Metric**: Minimum marine distance (cost-distance)
- **Analysis**: EMD vs. geographic distance regression
- **Output**: Labeled population pair scatter plots, statistical models

## Key Parameters & Assumptions

| Parameter | Value | Justification |
|-----------|-------|-----------------|
| KDE bandwidth (Script 2) | 1.86° | Reference bandwidth (href) |
| Minimum locations per individual | 30 | Balance data richness vs. sample size |
| Raster resolution (Script 3) | 0.5° | Balance computational load & detail |
| Raster resolution (Scripts 6-7) | 0.25° | Adequate for Mediterranean (~25 km) |
| Random absence ratio | 1:1 | Standard practice for SDMs |
| BART hyperparameters | Default | Embarcadero defaults |
| EMD grid aggregation | factor=2 | Computational efficiency |
