# Puffinus-Spatial-Ecology

## Overview

This repository contains a multi-level spatial ecology analysis of Mediterranean *Puffinus* shearwaters (Balearic and Yelkouan shearwaters). The project integrates GLS tracking data, migration phenology, connectivity analyses and environmental niche modeling to understand migratory patterns, habitat use, and biogeographic population structure across the Mediterranean Sea. A central focus of the project is testing whether spatial and ecological variation in these shearwaters follows a continuous longitudinal gradient across the Mediterranean—reflecting gradual environmental transitions—or whether populations instead align with discrete populations shaped by sharp ecological boundaries.

## Setup Instructions

#### External Environmental Data (Place in repo root or specify path in Script 6)**

Script 6 requires the original NetCDF files containing daily climatological data. The final processed raster layers used in the analyses are provided in the *climatology/ folders.

| Variable | Source | DOI | File Pattern |
|----------|--------|-----|--------------|
| Chlorophyll-a (CHLa), gradient | Copernicus | https://doi.org/10.48670/moi-00019 | `*.nc` |
| Net Primary Productivity (NPP) | Copernicus | https://doi.org/10.48670/moi-00019 | `*.nc` |
| Sea Surface Temperature (SST) | Copernicus | https://doi.org/10.48670/moi-00024 | `*.nc` |
| Sea Surface Salinity (SSS) | Copernicus | https://doi.org/10.48670/moi-00024 | `*.nc` |
| Mixed Layer Depth (MLD) | Copernicus | https://doi.org/10.48670/moi-00021 | `*.nc` |
| Sea Surface Height (SSH) | Copernicus | https://doi.org/10.48670/moi-00021 | `*.nc` |
| Wind Speed | Copernicus | https://doi.org/10.48670/moi-00181 | `*.nc` |
| Wind Stress Curl (gIUV) | Copernicus | https://doi.org/10.48670/moi-00021 | `*.nc` |

**Download instructions:**
1. Visit [Copernicus Marine Data Store](https://data.marine.copernicus.eu/)
2. Download daily grids for Mediterranean region (-15°E to 42°E, 28°N to 51°N)
3. Place `.nc` files in repo root or specify path in Script 6 (line 71)

## Execution Guide

### **Script Execution Order**

Some scripts builds on outputs from previous scripts. Follow this sequence:

| Order | Script | Input | Output | Duration |
|-------|--------|-------|--------|----------|

| Order | Script | Input | Output | Duration |

## Known Issues & Troubleshooting

### **Issue 1: Package installation fails**

```r
# For embarcadero (spatial BART):
# install.packages('devtools')
devtools::install_github('cjcarlson/embarcadero')
```
### **Issue 2: embarcadero workflow fails**

The `embarcadero` workflow requires `dbarts` version **0.9-22**. If a different version is installed, reinstall the required version before running the scripts:

```r
remotes::install_version("dbarts", version = "0.9-22")
### **Issue 3: NetCDF files not found (Script 6)**

- Download `.nc` files from Copernicus Marine Data Store
- Place them in repo root or modify path in Script 6 line 71:

  ```r
  wd <- "path/to/nc/files"  # Change this
  setwd(wd)
  ```
- ✓ Verify files match pattern `"*.nc"` with:
  ```r
  list.files(pattern = ".nc")
  ```
